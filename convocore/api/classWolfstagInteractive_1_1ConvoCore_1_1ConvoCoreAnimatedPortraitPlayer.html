Detailed Description

uGUI reference implementation of IAnimatedPortraitSurface: hosts animated expression playback on an existing portrait/slot Image.

Added lazily by the UI foundation via GetOrAdd. Other UI solutions implement IAnimatedPortraitSurface and tick playback their own way.
