Detailed Description

Base ScriptableObject class for all WitWeaver dialogue line actions.

Extend this class to run custom game logic before or after any dialogue line. Override ExecuteLineAction for forward playback and ExecuteOnReversedLineAction to undo side effects when the player steps back. Do not also inherit from MonoBehaviour or ScriptableObject directly — the base class handles that.
