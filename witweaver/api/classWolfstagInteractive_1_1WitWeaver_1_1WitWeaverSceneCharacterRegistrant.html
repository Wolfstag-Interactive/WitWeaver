Detailed Description

Add this component to any scene GameObject that should be driven by WitWeaver as a scene-resident character (i.e.

not spawned from a pool).

The component resolves an IWitWeaverCharacterDisplay from this GameObject or its children and registers it with a WitWeaverSceneCharacterRegistry on enable, unregistering on disable.

If no registry is explicitly assigned the component falls back to WitWeaverSceneCharacterRegistry.Instance (the first registry that awoke in the scene).

The characterId must match the CharacterID on the WitWeaverCharacterProfileBaseData used in the conversation.
