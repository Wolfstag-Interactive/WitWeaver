Detailed Description

Used as a basis of any UI that can be assigned in the inspector that includes all the base functions needed to interoperate with the dialogue state machine.

Representation-agnostic: subclasses are responsible for obtaining and using any WitWeaverPrefabRepresentationSpawner they need.

void WolfstagInteractive.WitWeaver.WitWeaverUIFoundation.RunExpressionActions ( CharacterRepresentationBase  representation,
string  expressionId,
int  lineIndex,
IWitWeaverCharacterDisplay  display 
)
inlineprotected

Runs the BaseExpressionAction ScriptableObjects attached to the given expression on the representation.

Call this from UpdateDialogueUI once a character's display has been resolved, after applying the built-in visual expression.

The display side (IWitWeaverCharacterDisplay.ApplyExpression) only handles built-in visuals; the representation owns the action list, so custom UI subclasses must call this to give those actions a chance to run. Safe to call with a null display (e.g. sprite representations) or a null/empty expressionId — both are no-ops.

Parameters
representationThe representation whose expression actions should run.
expressionIdThe expression being applied on this line.
lineIndexThe conversation line index, passed to the action context.
displayThe resolved display for this character, or null if none.
