Searches for an existing dialogue line in the provided conversation data.

Matches lines based on ConversationID and LineID if available, or falls back to the provided index.

Parameters
dataThe conversation data containing a list of dialogue lines to search.
keyThe unique identifier for the conversation to match.
lineIdThe unique identifier for the specific line of dialogue. Can be null or empty.
indexFallbackThe fallback index to use when LineID is not provided or no match is found by LineID.
Returns
The matching DialogueLineInfo instance if found, or null if no match is found.
