Always returns a SpriteExpressionMapping, or null only when ExpressionMappings is empty.

Null/empty ID selects the first mapping; an unknown ID logs a warning and falls back to the first mapping. Consumers should cast via is SpriteExpressionMapping and read its sprites/display options.
