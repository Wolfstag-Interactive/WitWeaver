Detailed Description

Character behaviour type for scene-resident characters that are driven by an Animator.

Resolves the scene-resident character via WitWeaverSceneCharacterRegistry, identical to ExternalBehaviour. The character's expression application is handled by a WitWeaverAnimatorDisplay component on the scene object.

This behaviour is a named variant of ExternalBehaviour provided as a convenience create-asset-menu entry to make the intended usage pattern explicit. Pair it with scene characters that have a WitWeaverAnimatorDisplay component.

Use case: fully animated scene-resident characters driven by an existing Animator controller.
