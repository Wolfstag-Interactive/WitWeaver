◆ ResolveRepresentation()

CharacterRepresentationBase WolfstagInteractive.WitWeaver.WitWeaverConversationData.ResolveRepresentation ( in CharacterRepresentationData  data,
string  fallbackCharacterId,
RepresentationRole  role 
)
inline

Single runtime resolution path from a line's representation entry to a representation asset.

Used by the runner, the UI foundation's expression-action pass, and the sample UIs; custom UIs should call this instead of hand-rolling resolution.

RepresentationRole.Speaker never resolves to null while the profile has any representation: an empty selection auto-assigns the first entry with a warning, and a stale ID warns once per session and substitutes the first entry. RepresentationRole.Visible treats an empty selection as a legal "None" and returns null silently.

Editor validation and inspectors intentionally do not use this path — they check the authored data via the quiet profile primitives (WitWeaverCharacterProfileBaseData.TryGetRepresentation and friends).

Parameters
dataThe line's representation slot entry.
fallbackCharacterIdCharacterID used to resolve the profile when the entry does not target an explicit participant — pass line.characterID for the speaker slot, null otherwise.
roleSpeaker or Visible slot semantics (see summary).
