Detailed Description

ScriptableObject that groups one or more WitWeaverConversationData assets into a single addressable unit for branching and playback.

Supports two modes: Playlist (play entries in sequence with optional looping) and Selector (pick one entry by alias, first match, random, sequential, or weighted random).
