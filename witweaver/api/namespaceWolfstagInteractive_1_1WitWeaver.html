◆ AudioBackend

enum WolfstagInteractive.WitWeaver.AudioBackend

Selects the audio playback backend for a WitWeaverAudioManifest.

Controls which fields are shown in the manifest inspector and how the runner resolves and plays audio at runtime.

Enumerator
UnityAudioSource 

Plays audio via Unity's built-in AudioSource.

Assign UnityEngine.AudioClip directly in each manifest entry slot. No extra components are required — the runner auto-provisions an AudioSource on its GameObject when none is manually assigned.

FMOD 

Audio is driven by FMOD Studio.

The runner triggers events using WitWeaverConversationData.DialogueLineInfo.LineID as the event key. Assign an FMOD adapter that implements IWitWeaverAudioProvider to the WitWeaver runner. AudioClip slots are not shown in the manifest inspector.

Wwise 

Audio is driven by Wwise.

The runner posts events using WitWeaverConversationData.DialogueLineInfo.LineID as the event key. Assign a Wwise adapter that implements IWitWeaverAudioProvider to the WitWeaver runner. AudioClip slots are not shown in the manifest inspector.

Custom 

A custom IWitWeaverAudioProvider drives playback.

Assign the provider component to the WitWeaver runner. Both AudioClip and WitWeaverAudioReference slots are shown in the manifest inspector.

◆ ConversationPresentationMode

enum WolfstagInteractive.WitWeaver.ConversationPresentationMode

Controls whether a dialogue line displays text, plays audio, or both.

Set per-line via WitWeaverConversationData.DialogueLineInfo.PresentationMode or as a conversation-level default via WitWeaverConversationData.DefaultPresentationMode.

Enumerator
AudioAndText 

Text is displayed in the UI.

Audio plays if a manifest and provider are assigned.

AudioOnly 

No text is sent to the UI.

Progression is driven by audio length or explicit input.

TextOnly 

Text is displayed.

Audio is not played even if a manifest and provider are present.

◆ RepresentationRole

enum WolfstagInteractive.WitWeaver.RepresentationRole

Role of a line's representation slot during resolution (see WitWeaverConversationData.ResolveRepresentation).

Enumerator
Speaker 

The index-0 speaker slot.

Never resolves to null while the profile has any representation: an empty selection auto-assigns the first entry with a warning, and a stale reference falls back loudly.

Visible 

A non-speaker visible slot.

An empty selection is a legal "None" and resolves to null with no logging.
