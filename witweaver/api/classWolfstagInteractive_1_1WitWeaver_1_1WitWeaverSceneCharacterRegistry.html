Detailed Description

Scene-level registry that maps developer-assigned string IDs to IWitWeaverCharacterDisplay instances that already exist in the scene.

Place one instance anywhere in the scene. Characters register themselves automatically via WitWeaverSceneCharacterRegistrant.

The first instance to awake is accessible via Instance. Multiple registries can coexist; only the first-awake one is reachable through the static property. Assign the registry directly on WitWeaverPrefabRepresentationSpawner when you need a specific instance.
