Detailed Description

Character behaviour type that places characters at scene-authored positions.

On OnConversationBegin: resolves each entry's WorldPointEntry.SpawnPointId against WitWeaverSpawnPointRegistry and creates a marker Transform at the matching WitWeaverSpawnPoint's world position and rotation. On ResolvePresence: spawns the prefab via the spawner and parents it to the marker for the character's slot index. Characters that appear on multiple lines are cached and not re-spawned. On OnConversationEnd: releases all spawned instances via the spawner and destroys the marker Transforms.

Place WitWeaverSpawnPoint components on scene GameObjects and position them visually; this asset references them by ID.
