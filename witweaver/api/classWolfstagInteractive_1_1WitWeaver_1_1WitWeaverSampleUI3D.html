Detailed Description

World-space dialogue UI for 3D character conversations.

No sprite support; no slot system. Character placement is entirely behaviour-driven via WitWeaverCharacterBehaviour.

Characters are persistent across lines. Expression application is the only per-line operation; characters are not despawned and re-spawned between lines.

WitWeaverCharacterBehaviour.OnConversationBegin is called when WitWeaver.StartedConversation fires. WitWeaverCharacterBehaviour.OnConversationEnd is called when WitWeaver.EndedConversation fires. The spawner is never called directly by this UI for release; that responsibility belongs to the behaviour.

Override point for rendering a dialogue line: set the text and speaker name, place and update character visuals.

Called once per line presentation (including when the player navigates back to a previous line).

Expression actions run automatically after this method returns, with a null Display in their context. Call RunExpressionActions yourself during rendering only when you can provide more — the resolved IWitWeaverCharacterDisplay on the prefab path, or exact timing relative to your visuals; anything you ran is not run again.
