bool WolfstagInteractive.WitWeaver.WitWeaverConversationData.LineContinuation.AllowGoBack

When true and Mode == PlayerChoice, a "Go Back" option is appended to the presented choices at runtime.

If selected, the runner revisits the previous dialogue line, allowing the player to re-read it before committing to a choice.
