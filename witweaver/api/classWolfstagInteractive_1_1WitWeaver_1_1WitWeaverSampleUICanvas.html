Detailed Description

Canvas-space dialogue UI supporting both sprite and prefab-in-canvas character representations.

Slot configuration is driven entirely by WitWeaverUIFoundation.DisplaySlots: each entry's WitWeaverUIFoundation.DisplaySlotDefinition.SlotObject serves as the anchor for prefab characters and the Image source for sprite full-body characters. Slot assignment uses DialogueLineDisplayOptions.DisplaySlot (named addressing) first, then index-based fallback.

Override point for rendering a dialogue line: set the text and speaker name, place and update character visuals.

Called once per line presentation (including when the player navigates back to a previous line).

Expression actions run automatically after this method returns, with a null Display in their context. Call RunExpressionActions yourself during rendering only when you can provide more — the resolved IWitWeaverCharacterDisplay on the prefab path, or exact timing relative to your visuals; anything you ran is not run again.
