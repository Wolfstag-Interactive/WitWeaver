Detailed Description

Contract between the WitWeaver runner and a dialogue UI implementation.

Implement (or extend WitWeaverUIFoundation) to display dialogue lines, present player choices, and signal advance/reverse input back to the runner.

Present a set of player choices and wait for the player to select one.

Implementations must set result.SelectedIndex before the coroutine completes. The base implementation auto-selects index 0 so the runner never hangs if no choice UI has been wired up.

Parameters
optionsThe choice options defined on the dialogue line.
localizedLabelsPre-resolved display strings, one per option.
resultShared result object; set SelectedIndex to signal completion.
